
# Netflix Clone 🎬

A responsive **Netflix landing page clone** built using **HTML5 and CSS3**.  
This project focuses on recreating the Netflix UI while practicing modern layout techniques and responsive design.

---

## ✨ Features

- Netflix-inspired UI design  
- Responsive layout using **Flexbox** and **Media Queries**  
- Hero section with background image overlay  
- FAQ section with SVG icons  
- Clean and structured CSS  
- Google Fonts integration  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  

---

## 📚 What I Learned

- Structuring real-world web pages  
- Flexbox for layout alignment  
- Responsive design principles  
- Working with SVG icons  
- CSS overlays and positioning
